# MISO CARD 이미지 자산 규격

실제 대표사진과 카카오/문자 링크 미리보기 이미지는 이 폴더에서 관리합니다.

- `representative.webp` — 박상욱 대표 실제 사진. 권장 800×800 이상, 정사각형, 얼굴/상반신 중앙.
- `og-card.jpg` — 카카오톡·문자·SNS 공유 대표 이미지. 권장 1200×630.
- `logo.png` — 미소주류 공식 로고. 투명 배경 PNG 권장.

## 교체 원칙
1. 실제 사진 파일을 위 이름으로 저장하면 카드 HTML에서 `/card-pro/assets/representative.webp`를 사용합니다.
2. OG 이미지는 `/card-pro/assets/og-card.jpg`로 고정해 링크 미리보기 캐시 관리가 쉽도록 합니다.
3. 대표/직원 사진은 외부 URL을 직접 연결하지 않고 저장소 자산으로 관리해 링크 깨짐을 방지합니다.
4. 실제 사진이 없는 동안에는 PSW/직원 이니셜 fallback을 유지합니다.
